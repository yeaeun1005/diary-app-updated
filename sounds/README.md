# sounds/

앱이 찾는 파일 이름이다(2026-09-14, mp3 셋). 파일이 없으면 그 소리만 조용히 건너뛴다.

| 파일 | 쓰임 | 길이·성격 | 음량 |
|---|---|---|---|
| `piano_loop.mp3` | 배경음. 내 섬·친구 섬·바다·광장에서 반복. 화면을 옮겨도 같은 `<audio>`가 이어진다(끊김·겹침 없음). 일기 화면에서는 멎는다 | 56초 루프 | 0.30 |
| `step.mp3` | 발걸음. 걷기 시작하면 루프로 틀고 멈추면 끈다. 파일에 발자국이 여러 개라 발과 맞추지 않는다 | 11초 | 1.0 (파일 자체가 작다) |
| `woosh.mp3` | 화면 전환. 잠수·광장·바다 셋 다 같은 소리로 한 번. 바다에서 친구 섬으로 떠날 때도 | 1.5초 | 0.10 (피크 0 dB라 배경음을 덮지 않게 낮춤) |
| (같은 `woosh.mp3`) | 튜토리얼 단계 전환음(2026-09-15). `SND.cfg.tut` — 1.8배 속도·음높이 같이 올림(preservesPitch=false), 별도 `<audio>`라 화면 전환음과 겹쳐도 안 끊긴다. 끝내기·건너뛰기엔 없음. 알맹이는 0.15~0.55초(0.9초 뒤는 −50 dB 아래) | 0.35초쯤 | 0.08 |

- **기본 음소거.** 3D 화면 오른쪽 위 "🔇 소리" 버튼으로 켠다. 선택은 기기에 남는다(localStorage `snd=on`).
- **음소거면 mp3를 받지 않는다.** `<audio>`는 소리를 켤 때 처음 만든다(배경음 1.1MB — 크롬북 첫 로딩 부담).
- 소리 버튼 클릭이 autoplay 정책을 푸는 첫 상호작용이다. 켠 채로 새로고침하면 다음 키·포인터 입력 때 배경음이 다시 시작된다.
- 출처는 루트 `CREDITS.md` "음원" 표에 적는다. CC0 등 라이선스가 명확한 것만.
- 음량 실측(2026-09-14): 배경음 가장 큰 0.1초 −19 dB·중앙값 −39 dB, 발걸음 가장 큰 0.1초 −39 dB, 전환음 피크 0 dB. 코드의 `SND.cfg`가 음량이다.
