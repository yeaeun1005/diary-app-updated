# sounds/

앱이 찾는 파일 이름이다. 이름마다 `.ogg`와 `.m4a` 두 벌을 둔다(브라우저가 재생 가능한 쪽을 고른다.
하나만 있어도 돌아간다). 파일이 없으면 그 소리만 조용히 건너뛴다.

| 파일 | 쓰임 | 길이·성격 |
|---|---|---|
| `waves.ogg` / `waves.m4a` | 배경 파도. 내 섬·바다·광장에서 반복 | 10~30초, 앞뒤가 이어지게(루프). 볼륨 0.35 |
| `step1` `step2` `step3` | 발소리. 걷는 동안 0.32초마다 셋을 번갈아 | 각 0.1~0.3초, 잔디 발소리 |
| `dive` | 잠수 — 캐릭터가 물에 닿는 순간 | 0.5~1.5초, 물보라 |
| `sail` | 출항 — 배가 부두를 떠날 때, 바다에서 항해 시작 | 1~3초, 물 밀리는 소리·작은 파도 |
| `tap` | 광장 표지 전환, 소리 켜기 확인 | 0.1~0.3초, 가벼운 클릭 |

- 기본 음소거. 3D 화면 오른쪽 위 "🔇 소리" 버튼으로 켠다. 선택은 기기에 남는다.
- **CC0만.** 출처는 `CREDITS.md`에 적는다.
- 변환: `.m4a`는 맥의 `afconvert`로 만든다 — `afconvert -f m4af -d aac -b 96000 in.wav out.m4a` (wav·flac·mp3 입력).
  `.ogg`는 `ffmpeg -i in.wav -c:a libvorbis -q:a 4 out.ogg` (ffmpeg가 없으면 원본이 ogg인 것을 고르거나 m4a만 둔다).
