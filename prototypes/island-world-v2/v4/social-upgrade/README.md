- 완료 퀘스트의 ‘다시 연습’을 제거했다. 마음 활동의 ‘탐험연습하기’는 별개 기능으로 유지한다.
- 내 섬 게시판 위의 중복 공중 간판을 제거했다. 게시판 표면의 한글은 유지한다.
- 친구 섬과 바다의 그림 제목·굵은 글꼴·큰 버튼·소리/시점 도구를 내 마음섬에 맞췄다. 친구 섬에서 상시 WASD/ㄷ 문구를 제거하고 캐릭터 위 E 그림을 표시한다. 실제 단축키는 유지한다. 부두 배와 게시판은 가까이서 흰 윤곽이 보인다.
- 친구 섬 부두 승선 뒤 내 섬으로 자동 항해하던 `autoHome`을 끈다. 우리 반 바다에 도착한 뒤 목적지를 선택한다.
- 바다의 친구 섬 미니어처를 새 내 섬의 지형·산책길·파스텔 나무·책상/관찰대/부두 구조로 통일했다. 공개된 감정 식생만 별도 생성한다. 재질별 묶음으로 미니어처의 반복 그리기 대상을 줄였다.
- 기존 네 정원에 노을빛 꽃마당·남쪽 소풍 정원을 더했다. 현재 총 여섯 곳이다. 기본 소품을 추가 지급하거나 보상 규칙을 변경하지 않는다.
- 친구의 공개된 마음 식물 → ‘나도 그래 · 마음 보내기’ → 선택적 100자 응원 글/예시 → 성공 시 별이 화면을 가로지른다. 기존 공감 조건과 같은 날/친구/어휘 중복 제한을 유지한다. 동작 줄이기에서는 별 이동을 숨긴다.
- 받은 응원 글은 ‘탐험 일지보기’ 아래 ‘친구가 보낸 마음’에 모인다. 전송 실패 시 입력을 지우거나 성공 연출을 하지 않는다.

## 일기 공개와 데이터 경계

- 모든 기존/새 일기는 기본 비공개다. 탐험 일지의 일기별 ‘이 일기 공개하기’에서 전체 글과 공개 범위를 확인한 뒤 ‘이 내용으로 공개하기’를 눌러야 공개된다.
- 친구 섬 상단 ‘공개 일기’와 기존 개인 공간 입구는 직접 공개한 사본만 보여준다. 비공개 일기 경로를 방문자가 읽지 않는다. 같은 학급 명단과 공개 사본의 학급 코드를 확인한다.
- 공개 사본은 `isle/<id>/shared/<entryKey>`에 날짜·원문·감정 이름·공개 시각·학급 코드만 저장한다. 일기/대화/분석 전체 객체를 복제하지 않는다.
- 원문 수정/삭제/전체 삭제와 해당 공개 사본 제거는 하나의 다중 경로 업데이트다. 실패하면 둘 다 유지된다. 수정하면 다시 공개를 선택해야 한다.
- 공개 전 원문을 재확인하고 섬의 `shareEpoch`를 거래 처리에서 비교한다. 다른 기기에서 글을 수정하는 중에 오래된 원문이 재공개되는 것을 막는다.
- 공개 일기 창은 5초 간격 및 창 복귀 때 갱신한다. 비공개 전환이 이미 열린 친구 창에 반영되기까지 최대 한 번의 갱신 지연이 있을 수 있다. 불러오기 실패 시 이전 글을 남겨두지 않는다.
- 운영 인증·Firebase 규칙을 변경하지 않았으며 실제 학생 자료는 조회/수정하지 않았다. 기존 클라이언트 인증 구조 위의 공개 사본 분리로, 새 서버 권한 보장을 주장하지 않는다.
