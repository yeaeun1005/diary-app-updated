## 발견한 기존 문제 — 미수정

새 교사 계정을 만든 직후 학생을 등록하면 **조치 기록을 불러오지 못했어요.**가 표시된다. `createSchool`에서 현재 사용자로 설정하는 `ns`에 교사 세션 해시 `th`가 없고, `V4Care.key`는 이를 요구한다. 일반 교사 로그인은 `th`를 채운다. 실제 로컬 조작에서도 로그아웃 후 다시 로그인하면 오류가 사라지고 학생 일기를 읽을 수 있었다.

이 문제는 심사용 날짜 설정과 무관하다. 이번 승인된 앱 수정 범위는 안내 한 문장 원복이므로 교사 등록 로직은 수정하지 않았다. ‘나머지 기능 전체 정상’으로 보고하지 않는다.

운영 Firebase·실제 학생 자료·실제 계정 생성에 접근하지 않았다. 실제 휴대폰·크롬북·물리 터치·성능은 미확인이다.
