- 개인정보 안내의 폐지된 체험 모드 보유기간 설명을 제거하고 개발·운영자 표현으로 정리했다.
- 일반 계정·교육 활동·개인정보 안내·동봉 라이선스 파일·역사 보관본은 유지한다.

## 생성과 확인

`python3 prototypes/island-world-v2/v4/public-home-cleanup/prepare.py`는 후보, 서비스 소스, 외부 연결을 차단한 메모리 검증본을 만든다. 운영 후보를 직접 브라우저에서 실행하지 않는다.

기존 production-transition/check-static.py와 check-accounts.cjs를 새 출력 경로로 실행했다. 계정 검사의 폐지 계정 오류 기대값만 새 일반 문구로 바꿨다. 정적 파일 100개 해시·상대 참조 240개·문법 67개, 일반 계정 저장·재로그인·실제 날짜·초기 저장 실패/복구·예약 계정 차단 모두 통과했다.

실제 데스크톱 격리 화면에서 학년/교과·저작권 버튼 제거, 개인정보 이동/홈 복귀, 빈 일반 로그인, 소리 버튼 변경을 확인했다. 최종 콘솔 오류 0개. 실제 운영 자료·물리 터치 기기·크롬북은 확인하지 않았다.

## 게시

release/install.py에 public-home-cleanup-20261112를 전달해 manifest 파일만 적용한다. 사용자 자동 배포 승인에 따라 이번 파일만 선택 커밋하고 origin/main에 일반 푸시한다. verify-public.py로 해당 커밋의 Pages 작업 성공 및 정적 응답 100개 일치를 확인한다. 운영 앱 실행이나 DB 접속은 하지 않는다.
