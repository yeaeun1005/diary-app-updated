- 마음 우체통/연습 화면에서 지정 문구를 삭제하고 세 게임 설명을 요청 문구로 교체했다.
- 기본 완료 조건: 오늘 날짜 일기 저장 + 분석 확인 + 마음 대화 저장. 대화할 내용이 없는 날은 학생이 ‘오늘은 대화할 내용이 없어요’를 명시적으로 선택한다. 이에 관해 사용자에게 두 해석을 질문했고 답변이 없어 첫 번째 기본 해석을 적용했다.

## 실제 컴퓨터 브라우저 조작

Firebase 제거 메모리 검증본에서만 확인했다.

- 학생 일기 저장 → 분석의 ‘짜증’ 표시 및 도움말 → 알게 된 점 저장/미루기 → 확인 → 대화 없음 선택 → 완료 화면.
- 기본 3단계에서 일기 저장 → 분석 확인 → 우체통의 짜증 자동 채움 → 욕구/행동/돌아보기 → 대화 저장 → 세 활동 모두 완료.
- 담임 1단계 선택·저장 → 로그아웃·가상 학생 로그인 → 일기 저장만으로 완료. 분석·대화는 ‘선택 활동’으로 표시.
- 나무 책상, 연습 카드, 삭제된 문구, 요청한 완료 제목/세 블록 순서 확인. 컴퓨터의 약 433px 좁은 창에서 가로 잘림 없이 표시. 브라우저 오류/경고 없음.

실제 휴대폰·크롬북·물리 터치와 성능은 미확인. 운영 계정 저장/운영 Firebase 접속은 하지 않았다. 학교의 실제 DB 규칙 적용 결과는 로컬 검증 범위 밖이다.
