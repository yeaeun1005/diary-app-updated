검토일: 2026-09-22. 첨부 KERIS 요강 54쪽을 추출하고, 공통 유의사항 및 교육용SW·AI 제출/저작권/서식 관련 페이지를 그림으로도 확인했다. 쪽수는 문서 하단 인쇄 쪽수다. 사용자 확인 제출 마감은 2026-09-23이다. 부문 회신 전까지 현재 앱에 해당하는 교육용SW·AI분과를 기준으로 정리한다. 지역별 추가 지침과 연구보고서 원본은 제공되지 않았다.

## 체험용 날짜가 오늘까지 보이는 문제

**첨부 요강에서 체험용 가상 데이터의 날짜를 현재 날짜에 맞추는 것을 직접 금지한 조항은 찾지 못했다. 이것만으로 위반이라고 판단할 근거는 없다.** 다만 주최기관이 승인한 방식이라는 뜻은 아니다.

현재 구현은 페이지를 연 날을 기준으로 가상 시나리오를 메모리에 생성한다. 실제 학생의 기록을 읽어 추가하는 기능이 아니며 새로고침하면 체험 중 입력이 초기화된다. 가상 학급 25명과 공개 예시 150편이 있고 실제 DB 참조 없이 학생/교사 화면에 연결되는 것을 검사했다. 로그인 안내에 가상 기록과 날짜 표시 방식을 명시했다.

가상 데이터를 실제 수업 효과, 학생 수, 활동 횟수, 사전/사후 변화의 근거에 섞으면 문제가 된다. 요강 27쪽은 존재하지 않는 자료를 실재한 것으로 제시하는 위조와 실제 자료를 임의로 바꾸는 변조를 규정한다. 5쪽은 연구 원자료 보관과 요청 시 제출을 요구한다. 실제 조사 원자료는 결과 발표일까지, 입상자는 최소 1년 이상 보관해야 한다.

제출 시 앱 버전과 파일 해시는 고정하고, 보고서/사용 설명에 아래 문구를 넣는 것을 권한다.

> 심사용 학급은 기능을 확인하기 위한 가상 예시입니다. 예시 날짜는 실행일을 기준으로 표시되며, 실제 학생 기록이나 연구 결과가 아닙니다. 새로고침하면 체험 중 입력한 내용은 초기화됩니다.

날짜 고정이 요구된다면 체험 화면의 기준일과 일기·최근 7일·공감 날짜 판단을 함께 맞춰야 한다. 예시 날짜만 과거로 고정하면 최근 기록과 교사 관찰 카드가 비어 보일 수 있다. 이번 구현에서는 기존 오늘 기준 동작을 유지했다. 제출 후 별도 웹 주소의 내용을 변경해 USB 소프트웨어/소스와 달라지게 하지 않는 것이 안전한 제출 관리 방법이다. 요강 19쪽은 USB 실행 심사와 실행물/소스 일치를 요구한다.

## 데이터 정리 방식

1. **가상 예시**: 프로그램의 `review-data.js`, `review-generator.js`, `review-class.js`. 기능 설명/시연 용도. 실제 연구 통계에서 제외한다.
2. **실제 연구 원본**: 학교의 승인된 보관 장소. 날짜·응답·학생 수를 변경하지 않는다. 이 저장소나 공개 사이트로 옮기지 않는다.
3. **익명화 연구 사본**: 참여자를 S01 같은 연구용 코드로 바꾼 사본. 대응표와 동의서는 별도 보관한다. 교실명, 실명, 사진, 일기 속 이름과 학교 추정 정보도 점검한다.
4. **분석 결과**: 관찰 기간, 포함/제외 기준, 누락 사유, 산식, 사용한 원본 버전을 기록한다. 날짜를 오늘로 이동하지 않는다.
5. **제출 자료**: 필요한 익명화 사례와 집계만 포함한다. 동의하지 않은 학생의 정보는 보고서에서 노출하지 않고 확인서 명단에서도 제외한다(50쪽).

실제 기록이 제공되지 않았으므로 학생별 데이터 정리/익명화/통계 검증을 완료했다고 보고할 수 없다. 이번 준비 폴더에는 실제 학생 자료를 넣지 않았다.

## 외부 권리 확인

- [Tripo 이용약관 5.2](https://www.tripo3d.ai/terms): 무료/유료 사용자 권리 규정이 다르다. 사용자가 제작 당시 유료 플랜 사용을 확인했다. 생성 시점 결제 내역과 원본 모델 증빙은 별도 보관해야 한다.
- [넥슨 공식 서체 조건](https://maplestory.nexon.com/Media/Font): 무료 사용·배포, 원래 배포 형태 유지, 임의 수정/편집 금지, 번들/임베드 시 저작권 안내 포함.
- [Pixabay 이용 조건](https://pixabay.com/service/license-summary/): 앱 내 사용과 음원 자체의 독립 재배포는 구분한다. 제출 원본과 에듀넷 공개 범위가 해당 이용 조건에 맞는지 확인해야 한다.

화면에서 ‘함께 사용된 도구’와 ‘배경이 된 이론 및 연구’ 소개는 요청대로 제외했다. 라이브러리의 필수 저작권 고지와 보고서의 연구 출처까지 삭제하는 것은 별개이므로 보존한다. 요강 16쪽의 개발 환경/도구 설명도 보고서에 작성해야 한다.
