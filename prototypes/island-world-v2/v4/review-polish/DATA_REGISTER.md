## 실제 연구자료를 받았을 때 작성할 기록

|---|---|---|---|---|---|---|---|---|
| 작성 필요 | | | | | | | | |

- 가상 예시를 실제 수업 인원, 활동량 또는 효과 분석에 합산하지 않는다.
- 실제 날짜와 원본 응답은 보존한다. 연구용 익명화 사본을 별도로 만든다.
- 일기 속 이름, 친구 이름, 학교·지역 추정 정보, 사진, 화면의 계정 정보를 점검한다.
- 동의하지 않은 학생의 정보는 보고서에 노출하지 않고, 서식 9 명단에서도 제외한다.
- 일반본과 블라인드본을 분리한다. 블라인드 소프트웨어·파일명·보고서에서 소속과 출품자를 유추할 수 있는 표시를 점검한다.
- 원자료는 요강에 따라 결과 발표일까지 보관하고, 입상 시 최소 1년 이상 보관한다.

## 제출 파일 잠금 기록

실행본과 source/runtime의 파일 해시는 `program-hashes.json`에 있다. 이 일치는 파일 복사 검증이며 USB 직접 실행, 모든 운영체제 호환성 또는 연구자료 정확성 검증을 대신하지 않는다. 제출 전 수정하면 실행본·소스·자산 목록·화면 사진을 같은 버전으로 다시 묶는다.
