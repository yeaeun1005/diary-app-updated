# 2026-09-20 달리기·게시판·교사 기록·학생 홈

사용자의 추가 4~6번 및 학생 홈 요청과 ‘이거 하고 배포’ 승인 범위다. 기존 학생 일기·분석·5단계 대화를 유지한다.

## 구현

- 내 섬/친구 섬 이동 속도 3 → 4.5(50% 증가), 애니메이션 주기 동기화. 지형·충돌·부두·항해·공감 경계 변경 없음.
- 게시판 두 안내 문구 교체. 5개 선택 제한과 기존 익명화/교사 검토/공개 조건 보존.
- 기존 말 걸기 시각·카드 숨김·사흘 뒤 재알림·지켜보기 해제 UI/상태 제거. 학생 카드는 그대로 두고 ‘더 지켜볼게요’ / ‘이렇게 조치했어요’를 선택한다.
- 조치 예시는 Wee클래스 상담선생님께 전달, 법적 보호자님께 전달, 학생과 개별 대화, 학교 상담 담당자와 상의. 복수 선택 가능. 기존 교사 전용 비밀 경로의 `/care/학생ID`에만 저장하며 외부 메시지를 보내지 않는다. 과거 `/talk` 값은 읽거나 변경하지 않는다.
- 교사 명단 ‘탐험일지’, 학생과 같은 달력 → 모든 일기 → 리포트, 최신 날짜 순서와 분석 그래프 재사용. 일기 읽기는 기존/이전된 경로를 엄격히 읽어 실패를 빈 목록과 구분하고, 학생을 바꾸는 동안 이전 학생 기록이 보이지 않도록 한다. 교사 화면에는 학생 일기 수정/삭제/공개 버튼이 없다. 조회하지 않는 학생 탐험 선택값은 0으로 집계하지 않는다.
- 학생 내 섬/친구 섬/바다에 홈 버튼. 로그인 유지 상태로 첫 표지를 보여주고 ‘내 섬으로 이어가기’로 복귀한다. 로그아웃은 기존 별도 동선 유지.

## 수행한 검증

- `check-care.cjs`: 교사 전용 경로, 소속 학생, 선택 예시, 여러 조치, 읽기/저장 실패, 교사 분리, 학생/공개 경로 변경 없음.
- `check-components.cjs`: 실제 후보 컴포넌트의 불러오기 실패/재시도, 실패 시 선택 유지와 성공 표시 금지, 교사 읽기 전용/학생 편집 보존, 최신순/일기별 분석, 엄격한 기존/이전된 일기 읽기.

- 기존 학생 분석 검사 및 현재 후보로 실행한 5단계 대화 회귀 검사 통과.
- 현재 후보로 실행한 social-upgrade 통합 검사 및 공유 검사 통과: 가상 학생/교사 로그인, 저장·역할 전환·선택 공개/철회·공감, 실제 DB 참조 0. 오래된 루트 `check-social.cjs`는 새 V4Sharing 의존성을 로드하지 않아 실행 실패하므로 현재 공유 모듈을 포함한 통합 검사로 확인했다.
