## 적용

- 일기 쓰기에서 지난 기록 시작 및 가상 이야기 탐험을 제거했다. 입력 안내는 ‘어떤 상황에서 어떤 감정을 느꼈나요?’다. 날짜, 작성 도움, 기존 일기/보관함은 유지한다.
- 분석은 변화 그래프 → 마음 원형 그래프 → 긍정/부정 TOP 10 → 긍정/부정 표현이 나온 상황 순서다. 탐험 진행 중에도 동일하다. 별도 상황 탐지, 고정된 짜증·화남·분노 뜻 설명 카드, 마음 나침반 토글을 제거했다.
- 마음 대화는 관찰 → 느낌 → 욕구 → 행동 → 돌아보기다. 각 단계에 사용자 요청 질문을 표시한다. 다음 질문을 누르면 새 질문과 단계 표시가 화면 상단으로 이동한다.
- 관찰은 상황 단어가 있는 일기 문장을 최대 두 문장 발췌한다. 없는 경우 첫 문장을 제시한다. 느낌은 기존 사전에서 찾은 감정만 채우며 미탐지 시 비워 둔다. 자동 감정/상황은 정확한 판정이 아닌 수정 가능한 시작점이다. 원래 일기는 바꾸지 않는다.
- 욕구/행동은 예시 버튼과 직접 입력을 제공하고, 돌아보기는 ‘도움이 되었어.’ / ‘보통이야.’ / ‘안됐어.’ 세 선택지와 예시를 제공한다. 기존 대화의 자유 입력 돌아보기와 다음 행동은 이어 쓰기/저장 시에도 보존한다.
- 대화의 수정한 관찰/느낌/욕구/행동/돌아보기를 기존 계정별 대화 저장 경로에 저장한다. 교사/기록 호환을 위해 기존 완료 표식을 유지한다. 데이터 이전은 없다.

Firebase SDK/초기화를 제거하고 `connect-src 'none'`을 적용한 로컬 메모리 검증본에서만 실행했다. 컴퓨터 브라우저 1280×720 및 390×844의 좁은 창을 확인했다.

- 일기 쓰기의 삭제 항목과 새 입력 문구, 실제 가상 일기 저장 성공.
- 그래프/분석 순서, 자세히 보기의 삭제 항목, 탐험 진행 중 동일 순서.
- 자동 상황/감정 채움 → 상황/감정 직접 고치기 → 욕구 예시 선택 후 고쳐 쓰기 → 행동 예시 → 돌아보기 선택 → 저장 완료 → 닫았다 다시 열어 저장 기록 확인.
- 좁은 화면 5단계 표시, 질문·입력·예시/선택지 가로 잘림 없음, 다음 질문으로 스크롤, 최종 후보 대화 저장 성공.
- `?saveFail=1` 검증본에서 실제 저장 실패 문구와 작성 내용 유지.
- 새 개인 일기 → 분석 → 생각 저장 → 피드백 → 탐험 완료/선물 진입 버튼. 기존 보상 흐름 유지.
- 브라우저 오류/경고 로그 없음. 마지막 소스 변경은 단계 전환 스크롤 보완이었고 최종 후보로 새로고침 후 재검증했다.

실제 휴대폰·크롬북·물리 터치·기기 성능은 미확인이다. 자동 탐지의 정확도를 모든 문장에 보장하지 않는다. 운영 학생 자료나 운영 Firebase는 조회·수정하지 않았다.
