새 연출 체험: ‘부두로 걷기’ → 아래 ‘바다로 · 배 타기’를 누르면 승선·출항합니다. ‘길을 따라 둘러보기’ → ‘내 안으로’로 걸어간 뒤 아래 행동 버튼을 누르면 잠수합니다. 연출 중 ‘바로 들어가기’로 건너뛰거나 ‘취소’/Escape로 돌아올 수 있습니다. 상단 ‘내 안으로’는 바로 활동을 여는 빠른 길입니다.

## 범위와 안전

남쪽 부두 → 중앙 마당 → 서쪽 게시판 → 연못 다리 → 동쪽 평온 정원 → 내 안으로 입구를 연결했습니다. 북쪽 활기, 남쪽 슬픔, 서쪽 떨림은 기본 이동 공간과 식생만 구성했습니다.

기존 검증 하네스의 Firebase 제거·메모리 DB 치환을 사용합니다. 생성 HTML의 Firebase 설정, SDK, 시연 학급 생성 코드는 제거합니다. CSP의 connect-src는 none입니다. 서버는 loopback 전용이며 운영 HTML과 시연 생성 경로는 제공하지 않습니다. 실제 학생 자료, 운영 Firebase, stash에 접근하지 않았습니다.

운영 index.html은 변경하지 않았습니다. 기존 DESIGN.md/HANDOVER.md의 미커밋 변경도 보존했습니다. 커밋·푸시·배포하지 않았습니다.

## 새 파일

- build.py: 기존 하네스에서 안전한 HTML 생성, 기존 게시판 기능을 섬 위 패널로 추출
- world.js: 가상 자료, 지형·식생·조명·카메라·걷기·충돌, 기존 활동 연결
- world.css: 시제품 UI
- explorer.js: 원본 탐험가 모델과 걷기/승선/잠수 자세, 기존 방문 화면의 캐릭터 크기 호환
- landing.js: 실제 섬 전경을 사용하는 첫 화면과 원래 로그인 연결
- social.js: 친구 공개 요약과 기존 공감 규칙의 화면 연결
- check-social.cjs: 숨김/공감 중복/일기 미조회/인증 함수 보존 검사
- passages.js: 위치 보존, 접근/승선/출항/잠수 전환, 취소/건너뛰기
- board.generated.js: 기존 PlazaView의 질문·답변 기능에서 생성한 UI. 직접 수정 대신 build.py 사용
- serve.py: 허용 경로만 제공하는 로컬 서버
- check.cjs: 메모리 게시판·익명화·노출 조건 및 안전 검사
- check-passages.cjs: 전환 중복 방지, 완료/취소/건너뛰기, 위치 복원과 캐릭터 크기 검사
- renders/harness/world-v2.html, v2-*.png: 무시된 실행/캡처 산출물

## 1차 당시 확인 기록

아래는 최초 시제품 당시 기록입니다. 친구 섬과 공감의 최신 확인은 VISIT_REVIEW.md를 우선합니다.

브라우저에서 중앙 마당→게시판 이동, 카메라 측면·후면 회전, 드래그 상하 각도, 확대, 현재 위치 기준 복귀를 확인했습니다. 게시판 열기·답 작성·저장·공개 답 3개 표시·닫기 동안 위치와 카메라 유지, 식생 수 불변을 확인했습니다. 개인 활동 화면을 열고 돌아왔습니다. 다리 옆 진입에서 걸리는 문제를 수정한 뒤, 중앙 마당에서 다리를 건너 평온 정원(x16.63, z-4.07)에 도착하고 자동 보행이 종료된 것을 확인했습니다. 390×844 화면에서도 UI 배치를 확인했습니다. 실제 터치 입력 검증과는 구분합니다. 기록 없는 섬은 어휘0/기록 식생0으로 표시됐습니다. 부두→우리 반 바다→친구 선택→항해→가상 친구 섬 입장→귀항→새 내 섬 복귀를 확인했습니다.

코드 기반 검사: 공개 답 0/2/3개 경계, 교사 검토 상태, 익명 사본에 학생 id 없음, 수정 시 공개 철회, 이름 보호, 게시판 저장으로 섬 자료 변화 없음, 어휘 중복 누적 방지, 별도 게시판 WebGL 생성 없음. 실행: `node prototypes/island-world-v2/check.cjs`.

## 1차 당시 성능과 현재 한계

Mac의 Codex 내장 Chromium, 1440×900, 픽셀 비율 최대1.5, 기본 그림자, 가상 어휘8개/기록 식생24개. 실제 측정 예: 약119 FPS, 프레임8.37ms, 다리 주변238 draw calls/665,242 triangles. 최초 장면 생성+첫 렌더 약122ms (전체 다운로드·페이지 진입 시간 아님). 장면 방향에 따라 수치가 달라집니다. 동일 조건의 기존 버전 대비 성능 비교는 미완료이며 크롬북 성능은 미확인입니다.

현재 미완료: 나머지 세 구역 상세 아트, 우리 반 바다에 멀리 보이는 섬 모형의 새 외형 적용, 운영 적용. 임의 추가 어휘의 새 식생 배치 확장도 후속 검증이 필요합니다. 친구 섬에 입장한 뒤에는 새 지형을 사용합니다. 게시판은 새 공간에서 기존 로직으로 작동합니다.

미확인: 실제 터치 기기의 핀치·이동 동시 조작, 크롬북, 모든 충돌 경계, 개인 활동 전체 회귀. 공감까지 포함한 전체 방문·귀환은 이번 로컬 컴퓨터에서 확인했습니다. 자동 경로의 모든 지점 검사와 실기기 보행 검증은 구분합니다.

시각 차이: 참고 이미지의 조밀한 수공예 오브젝트·나무 실루엣·재질 디테일에는 아직 차이가 있습니다. 현재는 코드로 만든 나무·꽃·물·돌·목재를 사용하며 외부 모델/유료 API는 도입하지 않았습니다. 후속 1순위는 이 구간의 구도와 재질에 대한 사용자 판단을 받은 뒤 나무 실루엣과 물가 디테일을 다듬는 것입니다. 승인 없이 다음 단계로 확대하지 않습니다.
